# 組織開発課ポータル バックエンド（GAS）

GitHub Pages は静的サイトのみなので、ログインとお知らせの保存は **Google Apps Script + スプレッドシート + Googleドライブ** で行います。

## 1. プロジェクト作成

1. [Google Apps Script](https://script.google.com/) を開く（組織開発課の Google アカウントで）
2. 「新しいプロジェクト」
3. プロジェクト名を `組織開発課ポータル` にする
4. `コード.gs` の中身を、このフォルダの `Code.gs` で置き換える
5. （任意）`appsscript.json` を「プロジェクトの設定 → マニフェストファイルを表示する」で反映

## 2. 初期化

1. エディタ上部の関数選択で `setup` を選び、実行
2. 初回は権限の承認が必要です（スプレッドシートとドライブ）
3. 実行ログに、作成されたスプレッドシートとフォルダの URL が出ます
4. `bootstrapAdmin` を開き、`PASSWORD` を実際の強いパスワードに書き換えて実行する
5. 実行後、`PASSWORD` を `CHANGEME` に戻すか、その行を削除する

## 3. ウェブアプリとしてデプロイ

1. 「デプロイ」→「新しいデプロイ」
2. 種類: **ウェブアプリ**
3. 次のユーザーとして実行: **自分**
4. アクセスできるユーザー: **全員**（組織内のみに制限すると、GitHub Pages からの取得が失敗します）
5. デプロイ後の URL（末尾が `/exec`）をコピー
6. サイト側の `assets/js/config.js` の `gasUrl` に貼る

```javascript
gasUrl: "https://script.google.com/macros/s/xxxxxxxx/exec",
```

## 4. 動作確認

ブラウザで次を開きます。

`（ウェブアプリURL）?action=ping`

`{"ok":true,"service":"od-portal"}` が返れば成功です。その後、ポータルの「管理者」からログインし、お知らせを投稿できます。

## 注意

- パスワードはスプレッドシートに平文では保存しません（ソルト付き SHA-256）
- 添付ファイルは Drive フォルダに保存し、「リンクを知っている人が閲覧可」にします。組織の共有制限で失敗する場合は、作成されたファイルを手動で共有してください
- 1ファイルあたり 8MB まで（GAS の制限のため）
- GAS のコードを直したあとは **「デプロイ → 新しいデプロイ」**（または「デプロイを管理 → 編集 → 新バージョン」）が必要です
- ログインに何度も失敗してロックされた場合は、エディタで `unlockLogins` を実行してください
- サイトからの通信は GET を使います（GAS の POST リダイレクト制限を避けるため）
